# GitHub Upload

The project is prepared for GitHub. The repository URL in the report is a placeholder because the final remote repository depends on the GitHub account used for submission.

```bash
git init
git add .
git commit -m "DBMS mini project - Student Information Management System"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/student-information-management-system-dbms.git
git push -u origin main
```

Do not commit `.env` or real database passwords.
